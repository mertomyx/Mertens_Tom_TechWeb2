Guide d’utilisation de mon site web
1. Accéder au site web
Pour accéder au site web, utilisez le lien suivant : https://github.com/mertomyx/v2

2. Navigation dans le site
Accueil : Contient une brève présentation du site et des liens vers les différentes sections.
Catalogue : Permet de visualiser les montres disponibles à la vente.
Historique des ventes : Affiche les informations sur les ventes réalisées.
Gestion des clients : Montre les détails des clients enregistrés.
3. Fonctionnalités principales
Acheter une montre depuis le catalogue :

Cliquez sur le bouton "Acheter" à côté de la montre de votre choix.
Remplissez les informations demandées :
Nom
Prénom
Email
Adresse postale
Une fois validé, l’achat est enregistré dans la base de données.
Consulter les informations des clients :

Rendez-vous sur la page Gestion des clients.
Visualisez les détails des clients enregistrés, y compris leur nom, email, adresse et les montres qu’ils ont achetées.
Consulter l’historique des ventes :

Accédez à la page Historique des ventes.
Visualisez les détails des ventes réalisées, y compris la montre vendue, le prix, la date de vente et le client.
4. Fonctionnalités techniques
Le site web est connecté à des fichiers JSON pour stocker les données des clients, des ventes et des montres.
Les fichiers JSON sont mis à jour dynamiquement lors des achats.
Le site est hébergé sur GitHub.
Conclusion
Ce site permet de gérer un catalogue de montres, d’enregistrer les achats des clients, et de consulter les informations des ventes et des clients.
